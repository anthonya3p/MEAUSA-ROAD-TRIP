# MEAUSA ROAD TRIP V6

Application mobile prête pour GitHub Pages.

## Installation

1. Décompressez le ZIP.
2. Envoyez **tout son contenu** à la racine du dépôt GitHub.
3. Conservez les dossiers `travel` et `vendor` avec leurs noms actuels.
4. Dans GitHub, ouvrez **Settings → Pages**, choisissez **Deploy from a branch**, puis `main` et `/ (root)`.

## Données

- Les étapes sont classées automatiquement par date.
- Le départ Dallas utilise des coordonnées fixes et ne peut plus être confondu avec la Floride.
- Les photos et documents sont conservés dans le stockage de l’application sur l’appareil utilisé.
- Le menu permet d’exporter une sauvegarde complète au format JSON et de la restaurer sur un autre appareil.
- Les documents acceptés peuvent peser jusqu’à 40 Mo chacun.

Les fonds de carte et le calcul de l’itinéraire nécessitent Internet. Le carnet et ses médias déjà enregistrés restent accessibles hors connexion.
