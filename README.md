# MEAUSA ROAD TRIP V2

Application HTML autonome pour GitHub Pages ou Vercel.

## Mise en ligne

Remplacez simplement l'ancien fichier `index.html` par le nouveau. Le visuel est directement intégré dans ce fichier : aucun dossier `assets` n'est nécessaire.

## Fonctions

- création et modification de plusieurs road trips ;
- ajout, modification, validation et suppression des étapes ;
- calcul automatique de la progression ;
- archivage des voyages terminés et consultation ultérieure ;
- choix d'une photo de couverture ;
- partage du résumé du voyage ;
- export et import d'une sauvegarde JSON.

Les données sont enregistrées dans le navigateur du téléphone. Elles ne sont pas synchronisées entre plusieurs appareils. Utilisez régulièrement **Options → Exporter une sauvegarde**.
