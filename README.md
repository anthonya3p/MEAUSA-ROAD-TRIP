# MEAUSA ROAD TRIP V5

Version mobile statique destinée à GitHub Pages.

## Installation

1. Décompressez le ZIP.
2. Envoyez tout le contenu du dossier dans votre dépôt GitHub : `index.html`, `app.js`, `styles.css` et le dossier `travel`.
3. Conservez exactement ces noms et cette organisation.

Les voyages, publications et documents sont enregistrés localement dans le navigateur utilisé.
