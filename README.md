# MEAUSA ROAD TRIP V2

Application HTML autonome pour GitHub Pages ou Vercel.

## Mise en ligne

Remplacez simplement l'ancien fichier `index.html` par le nouveau. Le visuel est directement intégré dans ce fichier : aucun dossier `assets` n'est nécessaire.

## Fonctions

- création et modification de plusieurs road trips ;
- ajout, modification, validation et suppression des étapes ;
- calcul automatique de la progression ;
- archivage des voyages terminés et consultation ultérieure ;
- choix d'une photo de couverture ;
- carte interactive automatiquement visible dans chaque road trip ;
- calcul du tracé routier, de la distance et du temps estimé ;
- ouverture de l'itinéraire complet dans Google Maps ;
- ajout de PDF, photos, billets et confirmations à chaque étape ;
- partage du résumé du voyage ;
- export et import d'une sauvegarde JSON.

Les données et documents sont enregistrés dans le navigateur du téléphone. Ils ne sont pas synchronisés entre plusieurs appareils. La carte nécessite une connexion internet. Utilisez régulièrement **Options → Exporter une sauvegarde** pour les données textuelles ; les fichiers joints doivent également être conservés dans leur emplacement d'origine.
